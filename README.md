# JST-Theme-Termux
## How To Use
```pkg update && pkg upgrade -y```
```pkg install git -y```
```git clone https://github.com/W-HAT909/JSThemeTermux```
```cd JSThemeTermux```
```chmod +x install.sh```
```./install.sh```

## Options
1. JakartaSecTeam Garuda Theme
2. JakartaSecTeam Red Theme
3. Delete Theme
4. Exit
